\newcommand{\ThesisAbstractText}{
Humanoid parkour requires robots to navigate complex obstacle-rich environments via dynamic maneuvers (e.g., stair climbing, gap crossing, obstacle avoidance). This thesis proposes a target-driven control framework integrating memory augmentation, attention mechanisms, and adversarial motion priors for robust parkour on the Unitree G1 humanoid robot.

Five key innovations are included: (1) temporally subsampled depth image stacks for temporal-spatial terrain representation; (2) a GRU-based memory module with consistency loss to preserve terrain context; (3) a cross-attention mechanism for task-relevant terrain focus; (4) a mixture-of-experts action head for adaptive skill specialization; (5) an adversarial motion prior (trained on human motion capture) to encourage natural gaits.

Trained via reinforcement learning in simulation and deployed without fine-tuning, the policy enables stable locomotion on diverse real-world terrains (stairs, slopes, platforms, irregular rocks). The attention module supports proactive terrain awareness and precise foothold selection, while the memory module retains critical context during temporary visual occlusion. Results validate the proposed perception design achieves efficient, natural parkour in simulation and real-world deployment.
}
